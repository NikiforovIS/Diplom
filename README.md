# Начальная настройка конфигурации «Управление IT-фирмой» (модуль ВКМ)

Данное руководство описывает порядок действий для перехода с исходной версии конфигурации на доработанную. Инструкция предназначена для специалистов заказчика, которые уже ведут учёт в системе.

Все новые объекты доступны в подсистеме **«ВКМ_ДобавленныеОбъекты»**.

---

## 1. Подготовка Телеграм-бота

Для того чтобы специалисты получали оповещения о новых заявках, предварительно нужно:
1. Создать в Телеграм-мессенджере бота и отдельную группу для уведомлений.
2. Получить токен бота и идентификатор группы — они понадобятся на следующем шаге.

Уведомления формируются автоматически при создании документа «Обслуживание клиента», а также при изменении даты работ или специалиста, назначенного на заявку.

---

## 2. Заполнение констант

В подсистеме **«ВКМ_ДобавленныеОбъекты»** откройте список констант и заполните следующие значения:

| Константа | Что указывать |
|---|---|
| `ВКМ_НоменклатураАбонентскаяПлата` | Элемент справочника «Номенклатура», соответствующий абонентскому обслуживанию. |
| `ВКМ_НоменклатураРаботыСпециалиста` | Элемент справочника «Номенклатура», соответствующий работам специалиста. |
| `ВКМ_ТокенУправленияТГБотом` | Токен, полученный при регистрации бота в Телеграм. |
| `ВКМ_ИдентификаторГруппыДляОповещения` | Идентификатор группы, в которую бот будет отправлять уведомления. |

> ⚠️ **Важно**: если хотя бы одна из номенклатурных констант не заполнена — документ «Реализация товаров и услуг» не будет автоматически заполняться по абонентскому договору.

---

## 3. Условия оплаты сотрудников

Откройте регистр сведений **«ВКМ_УсловияОплатыСотрудников»** и внесите данные по каждому работнику:
- для всех сотрудников — размер оклада;
- для специалистов дополнительно — процент от выполненных работ.

Эти данные используются при расчёте управленческой зарплаты документом «Начисление зарплаты».

---

## 4. Настройка графиков работы

1. В справочнике **«ВКМ_ГрафикиРаботы»** создайте нужный вид графика (например, пятидневную рабочую неделю).
2. Перейдите в подсистему **«Сервис»** и откройте обработку **«ВКМ_ЗаполнениеГрафикаРаботы»**.
3. Укажите год, номера выходных дней (например, `6,7`) и созданный график.
4. Нажмите кнопку **«Заполнить»**.

---

## 5. Настройка пользователей и прав доступа

1. В справочнике **«Пользователи»** создайте учётные записи для сотрудников.
2. На вкладке **«Права доступа»** назначьте соответствующие профили:
   - бухгалтер — профиль **«Бухгалтер ИТ фирмы»**;
   - кадровик-расчётчик — профиль **«Кадровик расчетчик»**;
   - специалист — профиль **«Специалист»**;
   - менеджер — профиль **«Менеджер»**.

Все профили групп доступа являются поставляемыми и не подлежат изменению.

---

## 6. Рекомендации для сотрудников разных ролей

**Кадровик-расчётчик:**
- Создать всех сотрудников в справочнике «Физические лица» и назначить каждому подразделение (оно используется для автозаполнения документов начисления).

**Бухгалтер:**
- Для массового формирования документов реализации за месяц использовать обработку **«ВКМ_МассовоеСозданиеАктов»** (выбирать предыдущий месяц).

**Менеджер:**
- При заключении договоров с видом **«Абонентское обслуживание»** обязательно заполнять: дату начала/окончания, стоимость часа работы, сумму абонентской платы. Без этого реализации не сформируются корректно.

---

## ✅ Чек-лист запуска

- [ ] Создан Телеграм-бот и группа для оповещений.
- [ ] Заполнены все четыре константы.
- [ ] Внесены оклады и проценты в регистр «Условия оплаты сотрудников».
- [ ] Настроены графики работы.
- [ ] Созданы пользователи и назначены профили групп доступа.
- [ ] Проведён инструктаж сотрудников по ролям.

*Проверка работоспособности:* Создайте документ «Обслуживание клиента», заполните табличную часть «Выполненные работы» и нажмите «Провести». Если движения по регистрам сформировались и ушло уведомление в Телеграм — настройка выполнена верно.
