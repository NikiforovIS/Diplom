# Инструкция по запуску автотестов Vanessa Automation

## 1. Подготовка демонстрационной базы
1. Скачайте файл `.dt` из раздела **Releases** репозитория.
2. Загрузите базу в 1С:Предприятие 8.3.27. При загрузке укажите, что база является **перенесённой**.
3. Убедитесь, что в базе есть пользователи: `Администратор`, `Специалист`, `Менеджер`, `Бухгалтер` с соответствующими профилями.

## 2. Настройка тестовой базы
1. В режиме конфигуратора откройте **Администрирование → Пользователи**. Выберите `Администратор` и снимите ограничения безопасного режима (если они включены).
2. Настройте тестовую базу для работы с библиотекой тестирования Vanessa Automation. Для этого нужно снять безопасный режим в режиме конфигуратора (администрирование – пользователи - администратор) 
3. В свойствах информационной базы (ярлык или список баз) укажите дополнительный параметр запуска:
   `/TESTMANAGER`

## 3. Запуск Vanessa Automation
1. Запустите базу в режиме 1С:Предприятие.
2. Откройте файл `vanessa-automation.epf`.
3. Перейдите на вкладку **«Клиенты тестирования»**.
4. Добавьте клиентов тестирования:

| Имя | Тип клиента | Доп. параметры |
|---|---|---|
| Специалист | Тонкий | `/N"Специалист"` |
| Бухгалтер | Тонкий | `/N"Бухгалтер"` |
| Менеджер | Тонкий | `/N"Менеджер"` |

*(Путь к инфобазе укажите тот же, где загружен .dt).*

## 4. Порядок запуска сценариев
Вкладка **«Запуск сценариев»** → **«Открыть feature-файл»**. Запускайте строго по порядку:
1. `Менеджер.feature` — создаёт документы обслуживания.
2. `Специалист.feature` — закрывает созданные обслуживания.
3. `Акты.feature` — массово создаёт реализации.
4. `Анализ.feature` — формирует отчёт и проверяет данные.

## 5. Возможные проблемы
| Проблема | Решение |
|---|---|
| Клиент не подключается | Проверьте, что база не занята другим пользователем и путь указан верно |
| Не работает `/TESTMANAGER` | Проверьте параметр запуска в свойствах базы |
| Блокируются действия | Проверьте безопасный режим |
